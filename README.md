# CS2807 - Deep Learning Laboratory

This repository contains the laboratory assignments, implementations, and projects completed as part of the **CS2807 - Deep Learning Laboratory** course.

The objective of this laboratory is to study, implement, and evaluate various deep learning models, starting from foundational building blocks implemented from scratch up to complex models using modern deep learning frameworks.

---

## 📂 Repository Structure

The repository is organized by laboratory assignments in individual subdirectories:

*   **[Single Layer Perceptron](file:///e:/CS2807-Deep%20Learning%20Laboratory/Single%20Layer%20Perceptron/)**: Implementing fundamental neural network components and perceptrons from scratch.

---

## 🛠️ Setup & Environment

To run the implementations in this repository, you will need a Python environment configured with standard scientific computing and machine learning libraries.

### Prerequisites
*   **Python 3.8+**
*   **Jupyter Notebook / JupyterLab** or **VS Code** (with the official Python and Jupyter extensions installed)

### Installing Core Dependencies
You can install the common libraries required for the laboratory assignments using:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn ipykernel
```

---

## 🚀 Running the Notebooks
1. Open the repository in your IDE or navigate to it via terminal.
2. Open the subdirectory for the specific lab assignment you wish to run.
3. Open the corresponding `.ipynb` notebook file.
4. Select your Python interpreter/kernel and execute the cells.
